# 食热量 · 拍照识别食物热量（微信小程序）

拍一张食物照片，识别食物种类和份量，估算这一餐的热量、蛋白质、脂肪和碳水，并记录每天的饮食。

## 现在能直接体验什么

- **拍照 / 相册选图** → 结果页
- **演示模式示例识别**：未接入识别接口时，结果页会给出带「演示」标注的示例餐（米饭＋鸡胸肉＋西兰花＋鸡蛋），让你跑通完整流程
- **手动添加食物**：内置 51 种常见食物营养库，可搜索添加，热量计算是真实的
- **调整克数**：每样食物可 ±10 克、输入或滑动调整，总热量实时重算
- **饮食记录**：按餐保存到本地，首页看今日进度，记录页看按日分组的历史和最近 7 天柱状图
- **每日目标**：默认 1800 千卡，可在「我的」里调整

## 怎么运行

1. 解压后打开**微信开发者工具** → 导入项目 → 选择本项目文件夹（shiwu-reliang-miniprogram）
2. AppID 先选「测试号」即可在模拟器和真机预览体验全部演示功能
3. 正式发布时改成你自己的小程序 AppID（project.config.json 里的 appid）

## 怎么接真实 AI 识别

识别流程：小程序把照片转 base64 → POST 到识别接口 → 接口返回 `{ foods: [{ name, grams, confidence }] }` → 小程序用本地营养库算热量。

项目自带云函数示例 `cloudfunctions/recognizeFood`：

1. 在微信开发者工具开通云开发，把 recognizeFood 云函数上传部署，并开启它的 HTTP 访问 / 云函数 URL 化，得到接口地址
2. 在云函数环境变量里设置你选的视觉模型平台参数：`VISION_API_URL`、`VISION_API_KEY`、`VISION_MODEL`（任何 OpenAI 兼容的多模态接口都可以，如腾讯混元视觉、通义千问 VL 等，以平台文档为准；Key 只放云端）
3. 把接口地址填到小程序「我的 → AI 识别接口」保存，之后拍照就是真识别
4. 若用自己的服务器接口，还要在小程序后台把域名加进 request 合法域名；云开发方式可免这一步（以微信最新文档为准）

未设置环境变量时，云函数会返回标注 `demo: true` 的示例数据，方便先验证链路。

## 文件结构

- `app.js / app.json / app.wxss`：全局逻辑、页面与 tabBar 配置、公共样式
- `config.js`：默认配置（识别接口、每日目标）
- `data/foods.js`：本地食物营养库与热量计算
- `utils/recognize.js`：识别调用（真实接口 / 演示模式）
- `utils/store.js`：本地记录存储与每日/7 日汇总
- `pages/index`：首页（拍照入口、今日进度、最近记录）
- `pages/result`：识别结果（编辑克数、添加食物、保存）
- `pages/history`：记录（7 天柱状图、按日分组、删除/清空）
- `pages/mine`：我的（每日目标、识别接口、关于）
- `cloudfunctions/recognizeFood`：识别云函数示例
- `WorkBuddy提示词.md`：粘贴到桌面 WorkBuddy 可继续开发同一项目的提示词

## 说明与免责

- 营养数值为每 100 克的大致平均值，参考常见食物成分表整理；烹饪用油、酱料、实际份量都会造成误差，结果仅供日常饮食管理参考，不能替代医生或营养师建议。
- 记录和设置只保存在用户手机本地，不上传服务器（照片仅在真实识别时发送给你配置的识别接口）。
- 发布前请在小程序后台完善隐私保护指引（相册/摄像头用途说明）。
